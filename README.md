## Фото блюд

2. Загрузи фото с именами из таблицы (jpg, лучше 800×640 или меньше). Пока фото нет, показывается нарисованная тарелка.

## Как добавить рецепт (виден всем)
Открой `recipes.js` на GitHub → карандаш, скопируй любую строку R(...), поменяй текст, Commit changes.

## Как добавить рецепт в боте
Кнопка «Добавить» → форма, фото выбирается с телефона. Такие рецепты хранятся на твоём устройстве (раздел «Мои»).
