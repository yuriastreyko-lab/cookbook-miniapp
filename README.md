# Домашняя кулинарная книга — Telegram Mini App

## Что работает
- каталог с демонстрационными рецептами;
- поиск по названию, описанию и ингредиентам;
- категории и избранное;
- просмотр ингредиентов и шагов;
- добавление собственных рецептов;
- адаптивный интерфейс;
- поддержка Telegram Web Apps API.

## Ограничение стартовой версии
Рецепты, которые добавляет пользователь, и избранное сохраняются только в localStorage его браузера. Это не общая база данных. Для публичного приложения с общими рецептами, комментариями, рейтингом и авторизацией далее нужно подключить облачную БД, например Supabase. У него есть бесплатный тариф, но с ограничениями.

## Бесплатное размещение на GitHub Pages
1. Создайте аккаунт на https://github.com/
2. Нажмите **New repository**, имя `cookbook-miniapp`, выберите **Public**.
3. Загрузите в корень репозитория `index.html`, `style.css`, `app.js`, `README.md`.
4. Перейдите **Settings → Pages**.
5. В **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажмите **Save**.
6. После публикации получите ссылку вида `https://ВАШ-ЛОГИН.github.io/cookbook-miniapp/`.

## Подключение к Telegram
1. Откройте https://t.me/BotFather.
2. Отправьте `/newbot` и выполните инструкции.
3. Сохраните токен у себя и никому его не передавайте. Не добавляйте токен в код сайта.
4. Отправьте `/setmenubutton`, выберите бота, задайте текст кнопки, например `Открыть книгу`, и вставьте HTTPS-ссылку GitHub Pages.
5. Откройте своего бота и нажмите кнопку меню.

Официальная документация Telegram: https://core.telegram.org/bots/webapps
