# Домашняя кулинарная книга — Telegram Mini App

## Как добавить рецепт (виден всем)
1. Открой `recipes.js` на GitHub → значок карандаша.
2. Скопируй любую строку `R(...)`, поменяй текст, не забудь запятую в конце строки (у последнего рецепта её нет).
3. Нажми **Commit changes** — через минуту рецепт появится в боте.

## Как добавить рецепт прямо в боте
Кнопка **＋** → заполни форму. Такие рецепты хранятся на твоём устройстве (раздел «Мои»), их можно изменить и удалить.

## Публикация
Загрузи все файлы в корень репозитория (GitHub Pages, ветка `main`, папка `/root`). Ссылка в BotFather остаётся прежней.
